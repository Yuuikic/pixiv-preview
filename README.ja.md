<p align="center">Pixiv 作品ホバープレビュー拡張機能</p>

<p align="center"><a href="README.md">简体中文</a> · <a href="README.en.md">English</a> · 日本語</p>

**P2** は、イラスト作品を素早くプレビューできる Chrome 拡張機能です。[Nazurin](https://github.com/y-young/nazurin) を使ったイラスト収集ワークフローにも最適化されています。

Pixiv のフォロー新着、検索結果、ランキング、ブックマーク、ユーザーページを閲覧する際、サムネイルにマウスカーソルを合わせるだけでその場で作品を確認でき、何度も新しいタブを開く必要がありません。

- **全体表示**：横長・縦長・長尺のイラストもトリミングせず、元のアスペクト比のまま全体を表示します。
- **複数ページ閲覧**：複数枚ある作品の全ページを、プレビューウィンドウ内でそのままめくって閲覧できます。
- **複数ウィンドウの固定と比較**：ワンキーでプレビューを画面上に固定（ピン留め）し、そのまま他の作品をホバーして複数作品を同時に並べて比較できます。
- **自由な移動と拡大縮小**：プレビューの位置を自由にドラッグ移動でき、マウスホイールやウィンドウ端のドラッグで比率を保ったまま拡大縮小できます。ページ両脇の余白への自動整列にも対応しています。
- **任意の Nazurin 連携**：自作の Nazurin サーバーに接続すれば、ワンキーで単一作品の送信や、固定中の全作品の一括送信が可能です。

## インストールと更新

### Chrome ウェブストアからインストール（推奨）

1. [P2：Pixiv ホバープレビューの Chrome ウェブストアページ](https://chromewebstore.google.com/detail/p2-pixiv-preview/mpdecaobbbnbfdbhnjnipbbepnokepbd) を開きます。
2. **「Chrome に追加」** をクリックし、ブラウザの案内に従ってインストールを完了します。
3. インストール後に設定タブが自動で開きます。簡単なセットアップガイドで操作を確認したあと、Pixiv のページを開くか再読み込みすると利用を開始できます。

ウェブストアからインストールした場合、新しいバージョンが公開されると Chrome によって自動的に更新されます。

`1.1.1` 以前から `1.2.0` 以降へ初めてアップデートする際、既存の設定・ショートカット・Nazurin 設定を引き継いだまま、新しいセットアップガイドが 1 回だけ自動で開きます。ガイドを開いた時点で表示済みとして記録されるため、閉じたりスキップしたりした後に以降のアップデートで再度開くことはありません。Pixiv は既定で有効ですが、これまで既定で動作していた Twitter/X と pixivision は「サイトアクセス権」から必要に応じて有効化し、対象ページを再読み込みしてください。

> [!NOTE]
> Chrome ウェブストアのアップデートは毎回ストアの審査を経るため、GitHub Releases より配信がやや遅れる場合があります。

### ローカルインストール（デベロッパーモード）

GitHub Releases の最新バージョンをいち早く試したい場合や、Chrome ウェブストアにアクセスできない場合に適しています。

1. [Releases](https://github.com/Yuuikic/pixiv-preview/releases) ページから最新の `P2-vX.Y.Z.zip` をダウンロードし、任意の固定フォルダに解凍します。
2. ブラウザのアドレスバーに `chrome://extensions/` と入力して開きます。
3. 右上の **「デベロッパーモード」** をオンにし、左上の **「パッケージ化されていない拡張機能を読み込む」** をクリックします。
4. 解凍した `manifest.json` が含まれるフォルダを選択します。
5. 開いている Pixiv タブを再読み込みすると利用を開始できます。

**ローカル版の更新方法**：新しいバージョンの ZIP をダウンロードして既存のフォルダに上書き解凍し、`chrome://extensions/` ページの P2 カードにある **「再読み込み」** をクリックしたあと、開いている対象サイトのタブを再読み込みしてください。プレビューが二重に表示されるのを防ぐため、ウェブストア版とローカル版を同時に有効にしないでください。

## 使い方

### 基本操作

初回インストール時、設定ページには 3 ステップの **セットアップガイド** と、その場でホバーや固定を試せるプレビュー体験エリアが表示されます。ガイドは設定ページ下部の「セットアップガイド」ボタンからいつでも再度開けます。

1. **ホバーでプレビュー**：作品のサムネイルにカーソルを合わせる（初期設定では約 0.5 秒）と、プレビューウィンドウが自動で開きます。
2. **プレビューを固定**：`S` キーを押すかプレビューウィンドウをクリックすると、画面上に固定されます。そのまま他のサムネイルをホバーして、複数の作品を並べて見比べることができます。
3. **移動・拡大縮小・ページめくり**：画像または下部バーの余白をドラッグしてウィンドウを移動できます。固定したウィンドウ内でホイールを回すか、ウィンドウの四辺・四隅をドラッグすると等倍で拡大縮小できます。複数ページの作品は下部バーの左右ボタンまたは矢印キー `←` / `→` でページを切り替えられます。
4. **一時非表示と閉じる**：下部バーの `×` をクリック（または固定したプレビューをダブルクリック）するとそのウィンドウを閉じます。`Esc` キーを押すと、現在のページにあるすべてのプレビューを一括で隠せます。

また、プレビューを固定すると、下部バーの **ブックマークに追加**（Pixiv）や **新しいタブで作品を開く** ボタンも利用できます。

### 操作とショートカット一覧

以下の英数字キーのショートカットは設定画面で自由に変更できます（ページの入力欄で文字入力中は反応しません）：

| 操作 | 動作 |
| --- | --- |
| サムネイルにホバー | プレビューを開く。カーソルを離したあとも初期設定で 0.5 秒間残るため、そのままプレビュー内にカーソルを移せます |
| `S` | 現在ホバー中のプレビューを固定。ホバー中のプレビューがない場合は、最前面の固定プレビューを解除 |
| `C` | 最前面のプレビューの作品詳細ページ URL をコピー（事前の固定は不要） |
| プレビューをクリック / 下部バーの「固定」 | プレビューをクリックすると固定して最前面に表示。下部バーの「固定」ボタンで固定状態を切り替え |
| 画像または下部バーの余白をドラッグ | プレビューの位置を移動（未固定のプレビューをドラッグすると自動的に固定されます） |
| ホイール回転 / ウィンドウ端をドラッグ | 固定したプレビュー内でホイールを回すか、ウィンドウの端をドラッグして等倍でサイズ変更 |
| `←` / `→` または下部バーのページボタン | 複数ページ作品の前のページ / 次のページに切り替え |
| 固定プレビューをダブルクリック / `×` をクリック | そのプレビューを閉じる |
| `Esc` | 現在のページの全プレビューを隠す。新しいプレビューを開いていなければ、10 秒以内に再度 `Esc` を押すと元の状態に復元 |
| `D` / `Shift+D` | 現在の作品を送信 / 固定中の全作品を Nazurin に一括送信（要 Nazurin 設定） |

### カスタマイズ設定

ブラウザのツールバーにある P2 アイコンをクリックすると設定ポップアップが開きます。ポップアップ右上のボタンをクリックすると、新しいタブで詳細設定ページを開けます。一般設定の変更は自動的に保存され、すぐに反映されます：

| 設定項目 | 説明と初期値 |
| --- | --- |
| **ホバー遅延** | サムネイルにカーソルを合わせてからプレビューが開くまでの時間（初期値 `500 ms`）。長くするとカーソルが通過した際の誤表示を減らせます |
| **プレビューの残存時間** | サムネイルからカーソルを離したあとに未固定のプレビューが残る時間（初期値 `500 ms`）。長くするとプレビュー内にカーソルを移動しやすくなります |
| **プレビュー下の作品を認識** | 初期値オン。未固定のプレビューが他のサムネイルに重なっているとき、下にある作品のプレビューへ直接切り替えられます。オフにすると、未固定プレビューの上にカーソルを移してそのまま現在の作品を見続けられます |
| **オリジナル画像を読み込む** | 初期値オフ。オンにすると、標準プレビューの表示後に高解像度の元画像を読み込んで置き換えます（読み込み時間と通信量が増加します） |
| **固定したプレビューを自動整列** | 初期値オフ。オンにすると、ショートカットキーでプレビューを固定した際、自動的にサイズを調整してサムネイル両脇の余白に整列します |
| **ショートカットキー** | 「固定／固定解除」（初期値 `S`）、「作品ページのリンクをコピー」（初期値 `C`）、「Nazurin に送信」（初期値 `D`）を任意の英字・数字キーに変更可能 |
| **送信成功後にプレビューを自動で閉じる** | 初期値オフ。オンにすると、作品リンクが Nazurin に受理された際に、対応するプレビューウィンドウを自動的に閉じます |

## マルチサイト対応とサイトアクセス権

Pixiv 以外にも、主要なイラストサイトでのホバープレビューや、Twitter/X・pixivision からの Nazurin 送信に対応しています。

### 対応サイトと機能

| サイト | 対応ドメイン | ホバープレビュー／固定 | Nazurin に送信 |
| --- | --- | --- | --- |
| **Pixiv** | [pixiv.net](https://www.pixiv.net/) | 対応 | 対応 |
| **Danbooru** | [danbooru.donmai.us](https://danbooru.donmai.us/) | 対応 | 対応 |
| **yande.re** | [yande.re](https://yande.re/) | 対応 | 対応 |
| **Konachan** | [konachan.com](https://konachan.com/)、[konachan.net](https://konachan.net/) | 対応 | 対応 |
| **Zerochan** | [zerochan.net](https://www.zerochan.net/) | 対応 | 対応 |
| **Twitter/X** | [x.com](https://x.com/)、[twitter.com](https://twitter.com/) | 非対応 | 対応 |
| **pixivision** | [pixivision.net](https://www.pixivision.net/) | 非対応 | 対応（記事内の Pixiv 作品リンク） |

### 他のサイトを有効にする

Pixiv はインストール時に既定で有効になっています。その他のサイトは必要なものだけを許可する仕組みになっており、**Nazurin を設定していなくても、Danbooru、yande.re、Konachan、Zerochan のホバープレビュー機能を有効にして利用できます**：

- **設定画面からまとめて許可**：P2 設定の **「サイトアクセス権」** を開き、利用したいサイトをクリック（または右上の「すべて許可」をクリック）してブラウザの確認ダイアログで許可したあと、対象サイトのタブを再読み込みすると反映されます。
- **閲覧中のページからワンクリックで有効化**：対応サイトを閲覧中にツールバーの P2 アイコンをクリックし、**「このサイトで有効化」** をクリックして許可したあと、現在のページを再読み込みします。
- **いつでも無効化可能**：「有効なサイト」一覧にある **「無効化」** をクリックすると、そのサイトでの P2 機能をオフにし、対応する任意アクセス権限を解放できます。Pixiv のインストール時権限は保持されます。また、Nazurin サーバーと同じドメインを共有している場合は、両方の機能が不要になるまで権限が保持されます。

有効化した画像サイトのリストページや検索ページでは、Pixiv と同じホバープレビュー、固定、移動、拡大縮小、ショートカット操作がそのまま使えます。

## 任意：Nazurin との連携

自作の **[Nazurin](https://github.com/y-young/nazurin) サーバー** を運用している場合、ブラウジング中に気に入った作品をその場で Nazurin に送信して収集できます。

### 接続設定

1. P2 設定を開き、**Nazurin → 接続設定** を開きます。
2. サーバーの **API Host** と **Bot Token**（Telegram Bot Token）を入力します。リモートサーバーには `https://` URL が必要です（ローカルでのテスト環境では `http://localhost` または `http://127.0.0.1` を使用できます）。
3. **「保存」** をクリックし、ブラウザの権限確認ダイアログでサーバーアドレスへのアクセスを許可します。
4. **「接続テスト」** をクリックします。テストに成功すると、プレビュー下部バーの Nazurin ボタンと送信ショートカットが有効になります（後から Host や Token を変更した場合は、再度保存と接続テストを行ってください）。

### 作品の送信方法

接続が完了すると、以下の方法で作品を Nazurin に送信できます：

| 操作方法 | 利用シーンと動作 |
| --- | --- |
| **`D` キーを押す**（またはカスタム送信キー） | **一覧ページ**：カーソルを合わせているサムネイル、プレビューウィンドウ、またはツイートを送信（遅延プレビューが開く前でもそのまま送信可能）<br>**詳細ページ**：作品ページやツイート詳細ページの任意の場所で押すと、現在表示中の作品を直接送信 |
| **`Shift+D` を押す** | **一括送信**：プレビュー対応サイトにて、現在のページで固定中のすべてのプレビュー作品を順番に一括送信 |
| **下部バーの Nazurin アイコンをクリック** | 固定したプレビューウィンドウの下部バーにあるアイコンをクリックして、その作品を単体送信 |

**サイト別のヒント**：
- **複数ページの作品**：1 ページ目のプレビュー中でも途中のページをめくっている状態でも、送信時には複数ページ作品全体がまとめて送信されます。
- **Twitter/X の送信**：ツイートカード（本文、画像、または投稿時刻エリア）にカーソルを合わせて `D` を押すと送信できます。リツイートは元のツイート、引用ツイートは外側のツイートを送信します。ツイート詳細ページや画像ビューア表示中に `D` を押すと、アドレスバーに対応するツイートを送信します。
- **pixivision の送信**：pixivision の特集記事ページで、紹介されているイラスト画像、作品タイトル、またはクレジット情報エリアにカーソルを合わせて `D` を押すと、対応する Pixiv 作品リンクを直接送信できます。
- **キューとステータス表示**：連続して複数の作品を送信すると自動的にキューに入り順番に処理され、ページ右下またはプレビューのステータス欄に結果がリアルタイム表示されます。通信エラーなどで失敗した場合は、再度キーを押すかアイコンをクリックして再試行できます。

> [!IMPORTANT]
> **「Nazurin に送信しました」という表示は、サーバーがリクエストを受理したことを意味し、画像のダウンロード完了を示すものではありません。** 実際のダウンロードや保存処理は Nazurin サーバー側でバックグラウンド実行されるため、最終的な結果は Telegram の通知でご確認ください。

## よくある質問（FAQ）

1. **Pixiv のうごイラ（Ugoira）が動かないのはなぜですか？**
   現在、うごイラ作品についてはプレビューウィンドウ内で静止画のカバー画像のみを表示します。

2. **一部の作品でプレビューが表示されないのはなぜですか？**
   現在ログイン中のアカウントに、元のサイトでその作品を閲覧する権限があるか確認してください（年齢制限、マイピク限定、削除済み、または地域制限のある作品など）。P2 は各サイトのアクセス制限に従っており、制限を回避することはありません。

3. **プレビュー下部バーのブックマークボタンがクリックできないのはなぜですか？**
   先にプレビューを固定（`S` キーまたはウィンドウをクリック）してください。また、ブックマークボタン連携は現在 Pixiv のみ対応しており、ページ上に該当作品のブックマークボタンが存在する必要があります。特殊なページでボタンが見つからない場合は、作品を新しいタブで開いてブックマークしてください。

4. **拡張機能の更新後やサイトの許可後にページが変化しないのはなぜですか？**
   すでに対象サイトのタブを開いている場合は、一度ページを再読み込みしてください。ローカルのデベロッパーモードでインストールしている場合は、ファイルを更新したあと先に `chrome://extensions/` で「再読み込み」をクリックし、その後ページを再読み込みしてください。

5. **Nazurin 送信ボタンが表示されない、または `D` キーを押しても反応しないのはなぜですか？**
   設定画面の Nazurin 設定で「保存」をクリックし、「接続テスト」に成功しているか確認してください。Pixiv 以外のサイトで利用する場合は、「サイトアクセス権」で対象サイトを有効化し、ページを再読み込みしていることも確認してください。

## プライバシーとライセンス

P2 はユーザーのプライバシーを重視して設計されています：
- **データ収集ゼロ**：アクセス解析やテレメトリは一切含まれておらず、閲覧履歴や個人データを開発者に送信・収集することは決してありません。
- **最小権限の原則**：インストール時に要求するのは Pixiv へのアクセス権限のみです。その他の対応サイトや自作 Nazurin サーバーのアドレスは、ユーザーが機能を有効化した際にのみ個別に許可を求め、不要になった時点で解放できます。
- **認証情報のローカル保存**：一般的な表示設定はブラウザの同期機能で同期されますが、Nazurin の API Host と Bot Token は使用中の端末のローカルストレージにのみ保存されます。Nazurin への送信時には正規化された作品ページ URL のみを送信し、サイトの Cookie、ログイン情報、画像データを送信することは一切ありません。
