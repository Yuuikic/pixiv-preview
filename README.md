<p align="center">轻量的 Pixiv 作品悬停预览扩展</p>

P²（P squared）是一个用于预览 Pixiv 作品的 Chrome 扩展，特别支持使用 [Nazurin](https://github.com/y-young/nazurin) 收藏图片的工作流。

浏览 Pixiv 的关注动态、搜索结果、排行榜、收藏和用户主页时，无需逐个打开作品页面就能欣赏图片。预览功能开箱即用，也可独立使用，无需配置 Nazurin。

- **完整看图**：横图、竖图和长图按原比例显示，不裁切。
- **多页翻阅**：在预览窗口中直接浏览同一作品的其他图片。
- **同时看多幅作品**：将窗口留驻（保持打开），继续预览其他作品。
- **自由调整窗口**：拖动位置，用滚轮或窗口边缘等比缩放。
- **可选 Nazurin 集成**：连接自己的服务，将作品提交给 Nazurin 收藏。

## 安装与更新

1. 在本仓库的 Releases 页面下载 `P2-vX.Y.Z.zip`，解压到文件夹。
2. 在 Chrome 地址栏打开 `chrome://extensions/`。
3. 打开右上角的“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择解压后包含 `manifest.json` 的文件夹，不要选择 ZIP 文件。
5. 打开或刷新 Pixiv 页面，即可开始使用。

**更新时**，将新版文件解压并替换到原安装文件夹，在 `chrome://extensions/` 点击 P² 的“重新加载”，然后刷新所有已打开的 Pixiv 标签页。设置页顶部可查看当前加载的版本。

## 开始使用

1. **悬停预览**：将鼠标停在作品缩略图上，默认等待 0.5 秒即可显示预览。
2. **留驻窗口**：按 `S` 或单击预览窗口，让它保持打开。之后可以继续悬停其他作品，打开多个窗口。
3. **调整与翻阅**：拖动图片或底栏空白处移动窗口，用滚轮或拖动边缘缩放；多页作品可用左右按钮翻页。
4. **关闭窗口**：点击底栏 `×` 关闭当前窗口，或按 `Esc` 暂时隐藏全部窗口。

留驻后，底栏还可以收藏作品或在新标签页打开作品详情。未留驻时，第一次点击工具区域只会留驻窗口，不会执行工具操作。

### 操作速查

以下为默认快捷键；在输入框中输入文字时不会触发。

| 操作 | 效果 |
| --- | --- |
| 鼠标悬停缩略图 | 显示预览；离开后默认短暂保留 0.5 秒，方便移入窗口 |
| `S` | 留驻当前悬浮预览；没有悬浮预览时，取消最上层窗口的留驻 |
| 单击窗口／底栏“留驻” | 单击窗口可留驻并将它置顶；底栏“留驻”可切换该窗口的留驻状态 |
| 拖动图片或底栏空白处 | 移动窗口；未留驻的窗口会自动留驻 |
| 在留驻窗口内滚动／拖动窗口边缘 | 等比缩放窗口 |
| `←` / `→` 或左右翻页按钮 | 切换当前操作窗口中多页作品的图片 |
| 双击留驻窗口的图片或空白处／点击 `×` | 关闭该窗口 |
| `Esc` | 隐藏当前标签页的全部窗口；10 秒内再次按下可恢复，前提是期间没有出现新预览 |

取消留驻后，窗口会按悬浮窗残留规则收起。同一作品在一个标签页内只保留一个窗口。当前标签页跳转、前进或后退会关闭预览；在新标签页打开作品不会影响当前页窗口。

### 调整设置

点击 Chrome 工具栏中的 P² 图标打开设置，也可通过设置右上角的按钮在独立标签页中查看。

| 设置 | 用途与默认值 |
| --- | --- |
| 触发延迟 | 悬停多久后打开预览，默认 500 毫秒；调长可减少误触 |
| 悬浮窗残留时间 | 离开缩略图后保留多久，默认 500 毫秒；调长更容易移入窗口 |
| 识别浮窗下方作品 | 默认开启，允许切换到被普通预览遮住的缩略图；关闭后移入浮窗可持续查看当前作品 |
| 加载原图 | 默认关闭；开启后在预览图显示后继续加载原图，可能增加等待时间和流量 |
| 自动排列留驻窗 | 默认关闭；开启后，留驻时自动缩放窗口并排列到作品缩略图两侧的空白区域 |
| 快捷键 | 可更改留驻键和 Nazurin 提交键，默认为 `S` 和 `D` |

一般设置自动保存并立即生效。设置界面会根据浏览器语言显示中文或英文。

## 可选：连接 Nazurin

如果你已有自己的 **[Nazurin](https://github.com/y-young/nazurin) 服务**，可以从 P² 提交整个 Pixiv 作品。没有 Nazurin 也不影响预览、翻页和留驻功能。

1. 打开 P² 设置，展开 **Nazurin**。
2. 填写服务的 **API Host** 和 **Bot Token**（Telegram Bot Token）。远程服务建议使用 HTTPS，避免凭据明文传输。
3. 点击“保存”，批准该服务地址的访问权限。
4. 点击“测试连接”。测试成功后，Nazurin 按钮和快捷键才会启用；修改配置后需要重新测试。

| 操作 | 效果 |
| --- | --- |
| 点击留驻窗口中的 Nazurin 图标 | 提交该作品 |
| `D` | 提交最上层可见窗口中的作品，无需先留驻 |
| `Shift+D` | 依次提交当前标签页中全部留驻窗口的作品 |

如果更改了提交快捷键，批量提交使用 `Shift` 加新按键。多页作品会整部提交，不只提交当前图片。排队或提交中的作品不会重复加入；失败后可手动重试，当前标签页跳转会取消尚未提交的项目。

**“已提交到 Nazurin”只代表服务已接受请求，并不表示下载完成。** 下载和保存由 Nazurin 完成，最终结果请以 Telegram 消息为准。

## 常见问题

1. **为什么动图不会播放？**

   目前 Pixiv 动图仅显示静态封面。

2. **为什么部分作品无法预览？**

   请确认当前账号在 Pixiv 上有权查看该作品。P² 不会绕过私密、删除、地区或账号访问限制；Pixiv 页面或接口变化也可能需要扩展更新。

3. **为什么收藏按钮不可用？**

   请先留驻窗口。如果 P² 无法找到当前网页中该作品对应的收藏按钮，预览内的收藏功能会保持禁用，可打开作品页面自行收藏。

4. **为什么更新后还是旧效果？**

   重新加载扩展后，还需要刷新已打开的 Pixiv 页面。可在设置顶部核对版本。

5. **为什么没有 Nazurin 按钮？**

   配置需要保存、获得访问权限并通过连接测试；修改配置后请重新测试。

## 隐私与许可

P² 只在 Pixiv 页面运行，不收集分析数据或浏览历史。一般预览设置可通过 Chrome 同步；Nazurin 地址和 Token 仅保存在本地。只有配置 Nazurin 时才会请求对应服务的访问权限，清除配置也会移除该权限。
