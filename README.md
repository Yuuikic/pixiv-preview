<p align="center">简体中文 · <a href="README.en.md">English</a> · <a href="README.ja.md">日本語</a></p>

**P2** 是一款用于快速预览插画作品的 Chrome 扩展，特别支持使用 [Nazurin](https://github.com/y-young/nazurin) 收藏图片的工作流。

浏览 Pixiv 的关注动态、搜索结果、排行榜、收藏和画师主页时，只需将鼠标悬停在缩略图上即可直接看图，无需频繁点开新标签页。

- **完整看图**：横图、竖图和长图均按原比例完整呈现，不裁切画面。
- **多页翻阅**：在预览浮窗内直接翻看多图作品的全部页面。
- **多窗留驻对比**：一键将浮窗留驻在画面上，继续悬停浏览并同时打开多幅作品。
- **自由移动与缩放**：随意拖动浮窗位置，通过鼠标滚轮或拖拽边缘等比缩放，也可自动排列到页面两侧。
- **可选 Nazurin 集成**：连接自建的 Nazurin 服务，一键提交单个作品或批量提交全部留驻作品。

## 安装与更新

### 从 Chrome 应用商店安装（推荐）

1. 打开 [P2：Pixiv 悬停预览的 Chrome 应用商店页面](https://chromewebstore.google.com/detail/p2-pixiv-preview/mpdecaobbbnbfdbhnjnipbbepnokepbd)。
2. 点击 **“添加至 Chrome”** 并按浏览器提示完成安装。
3. 安装后会自动打开设置页，可跟随简短的新手引导了解操作，随后打开或刷新 Pixiv 页面即可开始使用。

通过应用商店安装后，Chrome 会在新版本发布后自动完成更新，无需手动下载或重新加载。

从 `1.1.1` 或更早版本首次升级到 `1.2.0` 或之后的版本时，P2 会自动打开一次新版引导，保留已有偏好、快捷键和 Nazurin 配置。引导打开后即记录展示状态，关闭或跳过后，后续升级也不会再次自动打开。Pixiv 默认启用；原来默认运行的 Twitter/X 和 pixivision 需在“网站授权”中按需启用，并刷新对应网页。

> [!NOTE]
> Chrome 应用商店的每次版本更新都需要经过商店审核，因此商店版的更新推送可能会比 GitHub Releases 稍晚一些。

### 本地安装（开发者模式）

适合抢先体验 GitHub Releases 中的最新版本，或在无法访问 Chrome 应用商店时使用。

1. 前往 [Releases](https://github.com/Yuuikic/pixiv-preview/releases) 页面下载最新的 `P2-vX.Y.Z.zip`，解压到一个固定文件夹。
2. 在浏览器地址栏访问 `chrome://extensions/`。
3. 开启右上角的 **“开发者模式”**，点击左上角的 **“加载已解压的扩展程序”**。
4. 选择解压后包含 `manifest.json` 的文件夹。
5. 打开或刷新已有的 Pixiv 标签页即可开始使用。

**更新本地安装版**：下载新版压缩包并解压覆盖原文件夹，在 `chrome://extensions/` 页面点击 P2 卡片上的 **“重新加载”**，然后刷新已打开的网站标签页。请勿同时启用商店版与本地版，以免页面中出现重复浮窗。

## 快速上手

### 基本操作

首次安装后，设置页会提供三步 **新手引导**，并附带可交互的预览试用区；后续也可随时点击设置页底部的“新手引导”重新打开。

1. **悬停预览**：将鼠标停留在作品缩略图上（默认约 0.5 秒），自动弹出预览浮窗。
2. **留驻浮窗**：按 `S` 键或直接单击浮窗，使其固定在页面上；之后可继续悬停其他缩略图，同时对比多幅作品。
3. **缩放与翻页**：拖动图片或底栏空白处可移动浮窗；在留驻浮窗内滚动滚轮或拖拽窗口边缘可等比缩放；多页作品可通过底栏左右按钮或方向键 `←` / `→` 翻页。
4. **隐藏与关闭**：点击浮窗底栏的 `×`（或双击留驻浮窗）关闭单个浮窗；按 `Esc` 键可一键隐藏当前页所有浮窗。

浮窗留驻后，底栏还会提供**收藏作品**（Pixiv）和**在新标签页打开作品**按钮。

### 操作与快捷键速查

以下快捷键支持在设置中自定义（在网页输入框打字时不会误触）：

| 操作 | 效果 |
| --- | --- |
| 鼠标悬停缩略图 | 打开预览浮窗；移开鼠标后默认短暂保留 0.5 秒，方便将鼠标移入浮窗 |
| `S` | 留驻当前悬停浮窗；若当前无悬停浮窗，则取消最上层浮窗的留驻 |
| `C` | 复制最上层浮窗的作品详情页链接（无需先留驻） |
| 单击浮窗 / 底栏“留驻” | 单击浮窗可将其留驻并置顶；点击底栏“留驻”按钮可切换留驻状态 |
| 拖动图片或底栏空白处 | 移动浮窗位置（未留驻的浮窗在拖动时会自动转为留驻） |
| 滚轮滚动 / 拖拽浮窗边缘 | 在留驻浮窗内滚动滚轮，或拖动浮窗四周边缘，可等比缩放大小 |
| `←` / `→` 或底栏翻页按钮 | 切换多页作品的上一张 / 下一张图片 |
| 双击留驻浮窗 / 点击 `×` | 关闭该浮窗 |
| `Esc` | 隐藏当前页面的全部浮窗；若期间没有打开新预览，10 秒内再次按 `Esc` 可原样恢复 |
| `D` / `Shift+D` | 提交当前作品 / 批量提交全部留驻作品至 Nazurin（需先配置 Nazurin） |

### 个性化设置

点击浏览器工具栏中的 P2 图标即可打开设置弹窗，也可点击弹窗右上角的按钮在独立标签页中打开完整设置。所有常规设置修改后自动保存并立即生效：

| 设置项 | 说明与默认值 |
| --- | --- |
| **触发延迟** | 鼠标在缩略图上悬停多久后打开浮窗，默认 `500 ms`。调长可减少快速扫过时的误触 |
| **浮窗残留时间** | 鼠标移开缩略图后浮窗继续保留的时长，默认 `500 ms`。调长更方便把鼠标移入浮窗 |
| **识别浮窗下方作品** | 默认开启。当未留驻的浮窗遮挡住其他缩略图时，允许直接切换预览下方的作品；关闭后移入浮窗可继续查看当前作品 |
| **加载原图** | 默认关闭。开启后会在标准预览图显示后继续加载高清原图并替换（会增加加载时间与流量消耗） |
| **自动排列留驻浮窗** | 默认关闭。开启后，按快捷键留驻浮窗时会自动缩放并排列到缩略图两侧的空白区域 |
| **快捷键** | 可分别修改“留驻／取消留驻”（默认 `S`）、“复制详情页链接”（默认 `C`）和“提交到 Nazurin”（默认 `D`）为任意字母或数字 |
| **提交成功后自动关闭浮窗** | 默认关闭。开启后，当作品链接被 Nazurin 成功接收时，自动关闭对应的预览浮窗 |

## 多站点支持与网站授权

除了 Pixiv 外，P2 还支持多个主流插画图站的悬停预览，以及通过 Nazurin 收集推文和专题插画。

### 站点功能支持

| 站点 | 支持域名 | 悬停预览／留驻浮窗 | 提交到 Nazurin |
| --- | --- | --- | --- |
| **Pixiv** | [pixiv.net](https://www.pixiv.net/) | 支持 | 支持 |
| **Danbooru** | [danbooru.donmai.us](https://danbooru.donmai.us/) | 支持 | 支持 |
| **yande.re** | [yande.re](https://yande.re/) | 支持 | 支持 |
| **Konachan** | [konachan.com](https://konachan.com/)、[konachan.net](https://konachan.net/) | 支持 | 支持 |
| **Zerochan** | [zerochan.net](https://www.zerochan.net/) | 支持 | 支持 |
| **Twitter/X** | [x.com](https://x.com/)、[twitter.com](https://twitter.com/) | 不支持 | 支持 |
| **pixivision** | [pixivision.net](https://www.pixivision.net/) | 不支持 | 支持（文章内的 Pixiv 作品链接） |

### 启用其他网站

Pixiv 在安装时已默认启用。其余站点采用按需授权，**即使不连接 Nazurin，也可以授权启用 Danbooru、yande.re、Konachan 和 Zerochan 的悬停预览功能**：

- **在设置中集中授权**：打开 P2 设置的 **“网站授权”** 区域，点击需要使用的站点（或点击右上角“全部授权”），在浏览器弹窗中确认权限后，刷新对应网站页面即可生效。
- **在当前网页一键启用**：浏览受支持的网站时，点击浏览器工具栏的 P2 图标，在展开的设置中点击 **“在此网站启用”**，授权后刷新当前网页即可。
- **随时停用**：在“已启用的网站”列表中点击 **“停用”**，即可关闭该网站上的 P2 功能并释放对应的可选访问权限。Pixiv 的安装权限会保留；与 Nazurin 服务共用的权限也会保留，直到两项功能都不再需要。

启用后的图站列表与搜索页会自动使用与 Pixiv 相同的悬停预览、留驻、移动、缩放和快捷键操作。

## 可选：连接 Nazurin

如果你部署了自己的 **[Nazurin](https://github.com/y-young/nazurin) 服务**，可以在浏览过程中随时把喜欢的作品发送给 Nazurin 收藏。

### 连接配置

1. 打开 P2 设置，找到 **Nazurin → 连接配置**。
2. 填写服务的 **API Host** 与 **Bot Token**（Telegram Bot Token）。远程服务需使用 `https://` 地址；本机调试服务可使用 `http://localhost` 或 `http://127.0.0.1`。
3. 点击 **“保存”**，并在浏览器提示中允许访问该服务地址。
4. 点击 **“测试连接”**。验证通过后，浮窗底栏的 Nazurin 按钮与提交快捷键即刻可用（修改地址或 Token 后需重新保存并测试）。

### 提交作品

连接成功后，可以通过以下方式将作品提交到 Nazurin：

| 操作方式 | 适用场景与效果 |
| --- | --- |
| **按 `D` 键**（或自定义提交键） | **列表页**：提交当前鼠标悬停的缩略图、预览浮窗或推文（预览浮窗尚未弹出时也可直接提交）<br>**详情页**：在作品或推文详情页任意位置按下，直接提交当前正在查看的作品 |
| **按 `Shift+D`** | **批量提交**：在支持预览的站点中，按顺序依次提交当前页面内所有已留驻浮窗的作品 |
| **点击浮窗底栏 Nazurin 图标** | 在已留驻的预览浮窗中，点击底栏图标单独提交该作品 |

**使用提示**：
- **多页作品**：无论是单张预览还是翻到了中间页，提交时都会将整部多页作品一并提交。
- **Twitter/X 提交**：将鼠标移到推文卡片（正文、图片或时间区域）上按 `D` 即可提交；转推会提交原推文，引用推文会提交外层推文；在推文详情页或大图查看器中按 `D` 会提交当前地址栏对应的推文。
- **pixivision 提交**：在 pixivision 专题文章页中，将鼠标移到插画图片、作品标题或信息区域上按 `D`，即可直接提交该插画对应的 Pixiv 作品链接。
- **排队与状态提示**：连续提交多个作品时会自动排队发送，页面右下角或浮窗状态栏会实时提示提交结果；若遇网络波动提交失败，可再次按键或点击图标重试。

> [!IMPORTANT]
> **“已提交到 Nazurin”仅代表服务端已接收请求，不代表图片已下载完毕。** 后续的下载与归档由你的 Nazurin 服务在后台处理，最终结果请以 Telegram 消息通知为准。

## 常见问题

1. **为什么 Pixiv 动图（Ugoira）不会动？**
   目前预览浮窗对动图作品仅展示静态封面图。

2. **为什么部分作品无法显示预览？**
   请确认你当前登录的账号在原网站有权限浏览该作品（如年龄限制、好P友限定、已删除或地区受限作品）。P2 遵循原站的访问控制，不会绕过任何权限限制。

3. **为什么浮窗底栏的收藏按钮无法点击？**
   请先将浮窗留驻（按 `S` 或单击浮窗）。另外，原站收藏按钮目前仅支持 Pixiv，且需要当前页面元素中存在对应的收藏入口；若部分特殊页面未提供入口，可点击打开作品详情页进行收藏。

4. **为什么扩展更新或授权后页面没有变化？**
   请刷新一次已打开的目标网页标签页。若为本地开发者模式安装，更新文件后请先在 `chrome://extensions/` 中点击“重新加载”，再刷新网页。

5. **为什么找不到 Nazurin 提交按钮，或者按 `D` 没反应？**
   请检查设置中的 Nazurin 配置是否已点击“保存”并通过了“测试连接”；若是在非 Pixiv 站点使用，还需确认已在“网站授权”中启用了当前网站并刷新过页面。

## 隐私与许可

P2 高度重视用户隐私：
- **零数据收集**：不内置任何统计分析工具，绝不向开发者收集或上传任何浏览记录与个人数据。
- **最小权限原则**：安装时仅默认申请 Pixiv 访问权限；其他受支持站点与自建 Nazurin 服务地址均由你按需授权，对应的可选权限在网站和服务都不再需要时释放。
- **凭据安全存储**：常规偏好设置可通过浏览器同步，而你的 Nazurin 服务地址与 Bot Token 仅保存在当前设备的本地存储中。向 Nazurin 提交作品时，仅发送规范化后的作品页面链接，绝不附带任何网站 Cookie、账号凭据或图片文件。

如需参与开发、运行测试或构建发布包，请参阅 [DEVELOPMENT.md](DEVELOPMENT.md)。
